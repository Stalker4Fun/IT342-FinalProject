# EcoBite: Surplus Food Rescue & Redistribution Network (IT342)

EcoBite is a web-based coordination platform connecting local food businesses (restaurants, cafes, grocery stores) holding surplus edible food with charitable organizations, shelters, and food banks.

## Increment 1: User Accounts and Authentication

### Architecture & Tech Stack
- **Frontend**: ReactJS (Vite, Tailwind CSS, React Router, Axios)
- **Backend**: Java 17+, Spring Boot 3.3.x, Spring Security 6, Spring Data JPA, JJWT 0.12+
- **Database**: PostgreSQL 16+
- **Security**: BCrypt hashing, Stateless JWT with database token revocation for logout, strict RBAC
